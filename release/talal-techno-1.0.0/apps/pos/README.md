# طلال تكنو — تطبيق نقطة البيع (Flutter)

تطبيق POS عربي أولاً، يعمل **دون اتصال**، مبني على Flutter + SQLite WAL مع
صندوق صادر (Outbox) للمزامنة، وطباعة ESC/POS تجريبية.

> **حالة التحقق:** هذا المشروع هيكل برمجي غير مُجمَّع في بيئة التسليم لأن
> Flutter وAndroid SDK غير متوفرين. راجع `docs/TESTING.md` لمصفوفة التحقق.
> لا تدّعي هذه النسخة وجود شهادة ZATCA أو SAMA أو دفع حقيقي.

## المتطلبات

- Flutter 3.24+ (يفضل 3.27+) وDart 3.5+
- Android SDK للبناء على Android
- خادم API يعمل على `http://<host>:4000` للمزامنة (اختياري للبيع)

## التشغيل

مجلدات المنصات (`android/`, `ios/`) غير مضمّنة حتى لا نُجمّع قوالب Gradle
غير مُتحقق منها. أنشئها مرة واحدة دون لمس كود `lib/`:

```powershell
cd apps/pos
.\tool\bootstrap.ps1 -ApiBaseUrl "http://10.0.2.2:4000"
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:4000
```

على محاكي Android استخدم `10.0.2.2` للوصول إلى جهاز التطوير. على جهاز حقيقي
استخدم عنوان IP للخادم على الشبكة المحلية.

## ما يعمل في الكود

| الطبقة | التفاصيل |
| --- | --- |
| قاعدة البيانات | `sqflite`، `PRAGMA journal_mode=WAL`، جداول المنتجات/الفواتير/الورديات/الصندوق |
| البيع دون اتصال | حفظ الفاتورة + بنودها + خصم المخزون + إدخال الصندوق في معاملة واحدة |
| المزامنة | `POST /sales`، `POST /shifts/open`، `POST /shifts/:id/close`، `GET /sync/pull` |
| إعادة المحاولة | كل عملية لها `attempts` و`last_error`، وتبقى في الصندوق حتى تنجح |
| الطباعة | `MockPrinterTransport` + أوامر ESC/POS (تهيئة، محاذاة، قطع) |
| الواجهة | RTL، أزرار لمس كبيرة، سلة، دفع نقدي/مدى/Apple Pay/شبكة، ورديات |
| الحماية | لا مفاتيح في الكود؛ رمز الدخول يُخزَّن محلياً بعد تسجيل الدخول |

## التدفق

1. عند أول تشغيل تُزرع قائمة تجريبية في SQLite.
2. أضف أصنافاً إلى السلة واضغط «الدفع» — يُحفظ البيع محلياً فوراً.
3. يُطبع إيصال تجريبي عبر Mock ESC/POS.
4. عند توفر الشبكة: سجّل الدخول من شاشة المزامنة ثم «مزامنة الآن».
5. تُرفع الوردية أولاً، ثم الفواتير، ثم إغلاق الوردية؛ ثم تُسحب القائمة.

## الاختبارات

```bash
cd apps/pos
flutter test
```

تغطي الاختبارات حساب الضريبة/الإجمالي، السلة، وأوامر الطباعة. اختبارات
قاعدة البيانات تحتاج `sqflite_common_ffi` (غير مضافة هنا) أو جهازاً/محاكياً.

## القيود المعروفة

- لا توجد منصات Android/iOS مُولّدة في المستودع؛ استخدم `tool/bootstrap.ps1`.
- الطابعة وهمية؛ لا اتصال Bluetooth/USB.
- لا توجد مدفوعات حقيقية أو تكامل ZATCA داخل التطبيق؛ كلاهما عبر API وSandbox.
- المزامنة تعتمد على API؛ لا تعمل دون خادم.
- التطبيق لم يُشغَّل أو يُختبر على جهاز فعلي في هذه البيئة.
