## [1.0.0] — 2026-10-27

**الإصدار الرسمي الأول** — نظام ERP + POS سعودي مفتوح المصدر، عربي أولاً، لمطاعم ومقاهي المملكة.

### أُضيف

- **عرض تجريبي كامل** في المتصفح (19 مساراً) يعمل دون خادم أو قاعدة بيانات، ببيانات مطعم سعودي جاهزة.
- **Monorepo إنتاجي**: NestJS API + Next.js Admin + Next.js E-Menu PWA + Flutter POS + Prisma/PostgreSQL + Redis/BullMQ + Docker/Nginx.
- **نقاط بيع POS**: محلي/سفري/توصيل/سيارة، طاولات، فواتير مفتوحة، تقسيم، نقل، خصومات، مرتجعات، ورديات، ESC/POS.
- **شاشة مطبخ KDS**: مؤقتات، حالات، 86-ing، وتحديث فوري من الطلبات.
- **قائمة QR / PWA**: قائمة عامة، طلب ذاتي، ربط الطاولة، ومانيفست وعمل دون اتصال.
- **محاسبة قيد مزدوج**: دليل حسابات، قيود تلقائية للبيع/المرتجع/المخزون، ميزان مراجعة، قائمة دخل، ميزانية عمومية.
- **مخزون BOM**: مواد خام، وصفات، توفر مشتق، هالك، تحويلات، جرد وتقييم.
- **ولاء وكوبونات**: كسب/استبدال/عكس، مستويات عملاء.
- **مشتريات وHR**: أوامر شراء، استلام، ورديات موظفين.
- **ZATCA Sandbox**: UBL 2.1، QR TLV، سلسلة تجزئة، توقيع ECDSA، تقارير Sandbox — **دون أي ادعاء اعتماد**.
- **تكاملات Adapter + Mock + Sandbox**: HyperPay/Geidea/Moyasar/PayTabs، HungerStation/Jahez/Mrsool/ToYou/Careem، طباعة حرارية.
- **أمان**: JWT، RBAC بثمانية أدوار، عزل مستأجرين، تدقيق، أسرار عبر `.env` فقط.
- **توثيق**: README، ARCHITECTURE، ROADMAP، DECISIONS، API، ERD، DEPLOYMENT، SECURITY، TESTING.
- **Docker Compose + Nginx + GitHub Actions + AGPL-3.0-or-later**.

### أُصلح أثناء التحقق التشغيلي

- بذرة البيانات: `NaN` في إجماليات الطلبات، وخلط مفاتيح Prisma العلائقية.
- ترتيب تواريخ فواتير ZATCA ليبقى سجل التجزئة إضافياً (append-only).
- حساب توفر أصناف القائمة من مواد الوصفة بدل صفوف مخزون الصنف نفسه.
- استجابة تحديث حالة الطلب كانت تعيد حالة بنود قديمة.
- تفعيل الطلب الذاتي للقائمة الإلكترونية في بذرة التطوير.
- توحيد إصدار Node.js إلى ≥ 22 وإخراج Next.js المستقل عبر `NEXT_STANDALONE`.

### تم التحقق منه

- `pnpm install` — 526 حزمة.
- `pnpm typecheck` — 11/11 مهمة.
- `pnpm build` — 7/7 مهام (Admin 16 مساراً، E-Menu 4 مسارات).
- `pnpm test` — 12/12 مهمة، منها 60/60 اختبار domain.
- API فعلي على PostgreSQL 17.10: `db push` + seed + بيع/مرتجع/طلبات/تقسيم/KDS/تكاملات/ZATCA.
- تشغيل Admin وE-Menu الإنتاجي: HTTP 200.

### قيود معروفة

- Docker Compose لم يُشغَّل في بيئة الإصدار (Docker غير متوفر).
- Flutter POS لم يُجمَّع (Flutter/Android SDK غير متوفر).
- Redis/BullMQ لم يُختبر تشغيلياً.
- لا اختبارات E2E أو عزل مستأجرين أو IDOR آلية بعد.
- لا ترحيلات Prisma مُصدَّرة (استُخدم `db push`).
- ZATCA/SAMA: Sandbox فقط، ولا يوجد اعتماد رسمي.
- الدفع/التوصيل: Mock/Sandbox فقط، ولا مفاتيح إنتاج.
